# 열차 좌석 감시 프로토타입

## 현재 포함된 기능

- 모바일 검색 화면
- 코레일 로그인/로그아웃 UI
- 열차 선택 및 좌석 무관 감시 설정
- 10초 단위 조회 주기
- 실행 상태 표시
- 텔레그램·이메일 알림 설정 UI
- 감시 작업을 관리하는 Python 표준 라이브러리 API 골격

## 실행 및 배포

```text
python server.py
```

서버 상태 확인 주소:

```text
http://127.0.0.1:8080/api/health
```

`server.py`가 화면과 API를 함께 제공하므로, 클라우드 서버에 `outputs` 폴더를 배포하면 스마트폰에서 하나의 주소로 접속할 수 있습니다. 배포 플랫폼이 `PORT` 환경변수를 제공하면 자동으로 해당 포트를 사용합니다. `Dockerfile`도 포함되어 있습니다.

Render를 사용하는 경우 저장소의 루트 디렉터리를 `outputs`로 지정하고 `render.yaml` 설정을 사용할 수 있습니다. 배포 후 Render가 제공하는 HTTPS 주소를 스마트폰에서 열면 됩니다. 환경변수 입력란에는 인증키·알림 토큰을 직접 등록하되, 저장소에는 기록하지 않습니다.

현재 API는 작업 상태만 관리하며 코레일 로그인, 좌석 조회, 결제, 알림 발송은 연결하지 않습니다. 실제 운영 전에는 HTTPS, 사용자 인증, 암호화된 세션 보관, 공식 연동 방식 검토가 필요합니다.

## 알림 환경변수

- `TELEGRAM_BOT_TOKEN`: Telegram BotFather에서 발급한 봇 토큰
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`: 메일 발송 계정

환경변수는 서버에서만 설정하며, 웹 화면이나 저장소에 넣지 않습니다.

서버를 재시작한 뒤 `/api/health` 응답의 `korail_key_configured`가 `true`이면 키를 읽은 상태입니다. 키 값 자체는 응답하지 않습니다.
